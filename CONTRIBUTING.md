# Как контрибьютить

Спасибо, что хочешь добавить MCP-сервер!

## Правила

1. Сервер должен иметь публичный репозиторий (GitHub, GitLab, Codeberg).
2. Активность за последние 6 месяцев (коммиты или релизы).
3. README должен описывать установку.
4. Описание на русском, 1-2 строки, по делу, без маркетинга.
5. Категория выбирается по основному назначению.

## Формат записи

```markdown
- **имя-сервера** — что делает в одной строке. [GitHub](https://github.com/owner/repo)
```

Если сервер реализует несколько разных функций (например, и БД, и поиск) — добавь его в **одну** наиболее подходящую категорию.

## Процесс

1. Форкни репо.
2. Добавь запись в правильную секцию `README.md` по алфавиту.
3. Открой PR с заголовком: `add: <имя-сервера>`.
4. В описании PR коротко: ссылка, что делает, чем полезен.

PR без описания или с маркетинговыми описаниями будут закрыты.
